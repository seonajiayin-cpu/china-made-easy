# China Made Easy

Address-first, coordinate-free China travel planning project (release 0.1.142).

## Current release

- Attraction records do not require latitude/longitude coordinates.
- Specific addresses are the location reference; Chinese addresses are required for mainland attractions.
- The itinerary planner supports editable morning/afternoon/evening slots, day locking, pinned slots, smart distribution, saved trips, versions, undo/redo, copy and print. Readiness scoring uses attraction matching, time balance and category variety; it does not perform geographic optimization.
- Route distances, GPS maps and travel-time calculations are intentionally not provided. Use an external map/transit app with the attraction address for current directions.
- Booking, opening hours, prices, closures and transport are not live verified; check official sources before travel.
- Localized attraction names are populated for six languages and marked machine-assisted draft. All 52 attraction summaries are populated across seven languages; machine-assisted drafts require editorial review. Editorial review is still required.

## Run

Requires Node.js.

```bash
npm run test:modules
npm run audit:content
npm run validate:localization
npm run validate:duplicates
npm run validate:ia
npm run build:preview
```

Open `preview.html` generated by the build for a local preview.

## Data policy

Attraction content uses names, descriptions, addresses, practical notes and source/verification metadata. GPS coordinate fields are not part of the data model.
