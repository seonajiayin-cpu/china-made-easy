# Phase 13 — Retired geographic replanning

The former Phase 13 planner used attraction coordinates and straight-line distance to reorder flexible itinerary slots. This implementation has been retired as part of the address-first planning cleanup.

Current replacement: users can manually edit and reorder activities, protect days/slots, distribute attractions by count, and review human-readable addresses. The application does not calculate GPS distances, geographic clusters, routes, or transfer times. Use an external map/transit service with the attraction address for current logistics.
