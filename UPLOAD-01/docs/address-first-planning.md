# Address-first planning

China Made Easy does not store GPS coordinates or calculate geographic distance, route order, map pins, or travel time. Attraction records use human-readable addresses. Mainland attraction records should include a Chinese-language address where available.

The planner supports count-based distribution, visit-duration estimates, manual stop ordering, day/slot editing, pinning, day locks, and saved-trip workflows. Any transfer buffer is a manual planning allowance, not a computed travel estimate. Users should verify exact entrances and current directions with a map or transit app using the attraction address.

Area-level destinations (such as historic districts, villages, lakes, or scenic regions) must be labeled as area references and must not be given fabricated street addresses.
