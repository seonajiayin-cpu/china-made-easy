# Phase 45 — Multi-City Trip Builder

Adds a lightweight multi-city route builder while preserving the existing single-city itinerary planner.

- Add/remove supported cities, allocate 1–7 days per stop, reorder stops.
- Auto-allocate a 10-day route across current stops.
- Save/load route locally on the device.
- Load the first route stop into the existing single-city planner as a handoff.
- Explicitly does not calculate transfer days, live transport time, route schedules, prices, or merge city itineraries.
