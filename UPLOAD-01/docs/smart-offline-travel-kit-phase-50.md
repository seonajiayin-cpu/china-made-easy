# Phase 50 — Smart Offline Travel Kit

A local-only travel information panel for essential accommodation details, emergency contacts, insurance assistance, booking notes, pre-trip offline checklist, Chinese help phrases, JSON export/import and printable copy.

## Privacy and limitations
- Data is stored in the current browser's local storage.
- Users should avoid storing full passport numbers, payment data, passwords or other secrets.
- Exported JSON is a user-controlled backup.
- No live service, emergency response, booking validation or travel-rule verification is provided.
- Print output is a compact offline reference, not a guarantee of accuracy.

## Validation
Run `npm run validate:phase50`.
