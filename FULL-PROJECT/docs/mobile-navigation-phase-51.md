# Phase 51 — Mobile UX & Navigation Upgrade

## Added
- Global search panel for guide, city, tool, itinerary, and topic text.
- Search results link to matching sections/cards; results are limited to 12.
- Clear-search control and live result announcements.
- Mobile bottom navigation: Home, Explore, Plan, Travel, My China.
- Active-state styling for quick navigation.
- Safe-area-aware fixed navigation on mobile.
- Reduced-motion support.

## Limitations
- Search is local text matching over existing rendered content; it is not semantic search.
- Search results are based on current page content and anchors, not external data.
- Bottom navigation is only displayed at mobile breakpoints.
