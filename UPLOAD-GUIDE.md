# GitHub upload guide

1. Open `UPLOAD-01`.
2. Upload the files and folders **inside** it to the repository root.
3. Preserve relative paths. Do not upload the `UPLOAD-01` folder itself.
4. The batch contains 93 files including its manifest, below the 100-file limit.
5. `FULL-PROJECT` is a complete backup for local use; it is not a nested repository upload.
6. After upload, enable GitHub Pages if you want the repository to be hosted as a website. GitHub repository browsing alone does not host the app.
